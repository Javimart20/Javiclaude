Importar Notas 📥

Trae tus entrenamientos desde la app Notas del iPhone/Mac

Paso 1 — Exportar tus Notas desde el Mac (1 vez)
1Abre Script Editor en tu Mac (búscalo en Spotlight con ⌘+Espacio).
2Copia el script de abajo, pégalo en Script Editor y pulsa el botón ▶ Run.
3Se creará el archivo javitrack_notas.txt en tu Escritorio. ¡Puede tardar unos minutos con 2000 notas!
Script AppleScript para Mac:
tell application "Notes" set allNotes to every note set exportContent to "" set noteCount to count of allNotes set i to 0 repeat with aNote in allNotes set i to i + 1 set noteTitle to name of aNote set noteBody to plaintext of aNote set noteDate to modification date of aNote set exportContent to exportContent & "===INICIO_NOTA===" & return set exportContent to exportContent & "TITULO:" & noteTitle & return set exportContent to exportContent & "FECHA:" & (noteDate as string) & return set exportContent to exportContent & "CONTENIDO:" & return set exportContent to exportContent & noteBody & return set exportContent to exportContent & "===FIN_NOTA===" & return & return end repeat end tell set filePath to ((path to desktop as text) & "javitrack_notas.txt") set fileRef to open for access file filePath with write permission set eof of fileRef to 0 write exportContent to fileRef close access fileRef display dialog "¡Listo! Se exportaron " & i & " notas al Escritorio como 'javitrack_notas.txt'" buttons {"OK"} default button "OK"

Accede a tus datos en cualquier dispositivo

No configurado — los datos solo se guardan en este dispositivo
Paso 1 — Crea tu base de datos gratis (solo la primera vez)
1Ve a supabase.com y regístrate gratis (con Google o email).
2Crea un proyecto nuevo (nombre libre, recuerda la contraseña).
3En el panel izquierdo abre SQL Editor y ejecuta este código (botón ▶ Run):
create table workouts ( id text primary key, user_code text not null, name text not null, date text, duration text, category text, intensity int default 2, notes text default '', exercises jsonb default '[]', created_at timestamptz default now() ); alter table workouts enable row level security; create policy "open" on workouts for all using (true) with check (true);
Paso 2 — Copia tus credenciales de Supabase
4En Supabase, ve a Settings → API (icono ⚙️ en el panel izquierdo).
5Copia la Project URL y la anon public key y pégalas abajo.
